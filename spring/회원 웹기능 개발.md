## 회원 웹 기능 - 홈화면 추가

**홈 컨트롤러**
lagom/lagom_spring/controller/HomeController.java

```java
package lagom.lagom_spring.controller;

import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.GetMapping;

@Controller
public class HomeController {
    /**
     * 홈 화면
     * @return
     */
    @GetMapping("/")
    public String home() {
        return "home";
    }
}
```

컨트롤러가 정적 파일보다 우선순위가 높다.

[localhost:8080/](http://localhost:8080/) 인 url로 이동을 할때 Controller탐색 후 해당 GetMapping이 없으면 /static/index.html로 이동한다.

## 회원 웹 기능 - 등록

**회원 컨트롤러**
lagom/lagom_spring/controller/MemberController.java

```java
package lagom.lagom_spring.controller;

import lagom.lagom_spring.domain.Member;
import lagom.lagom_spring.form.MemberForm;
import lagom.lagom_spring.service.MemberService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Controller;
import org.springframework.ui.Model;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PostMapping;

import java.util.List;

@Controller
public class MemberController {
    MemberService memberService;

    @Autowired
    public MemberController(MemberService memberService) {
        this.memberService = memberService;
    }

    /**
     * 회원가입 화면 이동
     * @return
     */
    @GetMapping("/members/new")
    public String createForm() {
        return "members/createMemberForm";
    }

    /**
     * 회원가입 이벤트
     * @param form
     * @return
     */
    @PostMapping("/members/new")
    public String create(MemberForm form) {
        Member member = new Member();
        member.setName(form.getName());

        memberService.join(member);
        return "redirect:/";
    }
}

```

## 회원 웹 기능 - 목록

**회원 컨트롤러 조회**
lagom/lagom_spring/controller/MemberController.java

```java
package lagom.lagom_spring.controller;

import lagom.lagom_spring.domain.Member;
import lagom.lagom_spring.form.MemberForm;
import lagom.lagom_spring.service.MemberService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Controller;
import org.springframework.ui.Model;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PostMapping;

import java.util.List;

@Controller
public class MemberController {
    MemberService memberService;

    @Autowired
    public MemberController(MemberService memberService) {
        this.memberService = memberService;
    }

    /**
     * 회원 조회
     * @param model
     * @return
     */
    @GetMapping(value = "/members")
    public String list(Model model) {
        List<Member> members = memberService.findMembers();
        model.addAttribute("members", members);
        return "members/memberList";
    }
}
```

**회원 목록 화면**
templates/members/memberList.html

```html
<!DOCTYPE HTML>
<html xmlns:th="<http://www.thymeleaf.org>">
<body>
<div class="container">
  <div>
    <table>
      <thead>
      <tr>
        <th>#</th>
        <th>이름</th> </tr>
      </thead>
      <tbody>
      <tr th:each="member : ${members}">
        <td th:text="${member.id}"></td>
        <td th:text="${member.name}"></td>
      </tr>
      </tbody>
    </table>
  </div>
</div> <!-- /container -->
</body>
</html>
```
