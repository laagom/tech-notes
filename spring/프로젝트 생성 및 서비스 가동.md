1. Java 17 설치

자바의 설치를 진행함에 있어 MacOS에서는 `homebrew`로 프로그램을 설치하는 것이 편리함으로 먼저 homebrew를 설치하자.

[Homebrew](https://brew.sh/ko/)

1. Java 버전 찾기
```Shell
>brew search openjdk
> Formulae
openjdk@17 ✔  openjdk  openjdk@11 ✔  openjdk@21  openjdk@8
> Casks
openttd
```

2. Java openjdk 11설치  
```Shell
>brew install openjdk@17
-----------------------------
# 전체 명령어는 /opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk 경로에 있는 파일을 /Library/Java/JavaVirtualMachines/openjdk-17.jdk 경로에 심볼릭 링크로 연결
sudo ln -sfn /opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk /Library/Java/JavaVirtualMachines/openjdk-17.jdk 
# ~./zshrc에 openjdk 경로를 추가하여 커맨드에서 java, javac를 쉽게 실행할 수 있게 함
echo 'export PATH="/opt/homebrew/opt/openjdk@17/bin:$PATH"' >> ~/.zshrc 
# C/C++ 컴파일러에 전달되는 컴파일러 플래그를 설정하는 데 사용되는 환경 변수 
export CPPFLAGS="-I/opt/homebrew/opt/openjdk@17/include"
```
- openjdk 설치 후 아래 명령어를 실행.
- Spring 3 이상부터는 java 17이상 사용해야 함으로 현재 openjdk 기준으로 17버전이 있는지 확인 후 위의 과정을 openjdk17로 변경해서 신규로 설치 진행한다.

### 프로젝트 열기
1. 프로젝트 다운로드 후 해당 프로젝트의 build.gradle를 열면 프로젝트를 열 수 있다.

> [!NOTE]
> **build.gradle로 IntelliJ를 여는 이유!!**
>build.gradle 파일을 IntelliJ IDEA에서 열면 Gradle 빌드 시스템을 기반으로 프로젝트의 의존성, 빌드 설정, 테스트 등을 관리할 수 있다. 이 파일은 프로젝트의 구조와 빌드 방법을 정의하며, IntelliJ IDEA는 이를 통해 프로젝트를 자동으로 구성하고, 빌드 및 테스트 작업을 효율적으로 처리할 수 있도록 돕는다.

- 프로젝트 경로로 이동 후 `open .` 명령어로 finder를 열어보자.

### 프로젝트 실행
src>main>java>lagom>lagom_spring 하위에 있는 java파일열어보자. 제일 처음 만들어지는 .java파일이며 어플리케이션을 실행시키는 파일이다.

<img src="images/Pasted%20image%2020250614152554.png" width="400" alt="">
<img src="images/Pasted%20image%2020250614152603.png" width="400" alt="">
main을 실행시키면 web 서비스가 가동된다. SpringBoot는 내부에 tomcat과 apache를 내장하고 있어 별도로 연결하여 실행하지 않아도 서비스가 올라간다.

##### 서비스 확인하기
서비스가 가동되고 나면 console창에 아래와 같이 "Tomcat started on port 8080 (http) with context path '/'" 문구가 표시되는 것을 확인 할 수 있다.

아래의 주소를 브라우저에 입력하여 접속을 시도해보자.
- url : localhost:8080
<img src="images/Pasted%20image%2020250614152959.png" width="450" alt="">
아래와 같이 흰색 배경의 페이지가 `Whitelabel Error Page`로 뜨면 서버가 올라간 것을 의미한다.

아무것도 나오지 않는데 어떻게 서버가 올라간 것으로 판단하는지 서비스를 내리고 다시 접속해보면 알 수 있다.
