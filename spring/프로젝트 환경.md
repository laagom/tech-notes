# [Spring] 프로젝트 환경

> 작성일: 2025-06-15 · 태그: 프레임워크/스프링, 기초

### Gradle 설정
기본적으로 build.gradle 파일은 프로젝트의 라이브러리나 프레임워크 사용을 명시한 설정파일이다.

##### build.gradle 전체소스
```groovy
plugins {
	id 'java'
	id 'org.springframework.boot' version '3.4.4'
	id 'io.spring.dependency-management' version '1.1.7'
}

group = 'lagom'
version = '0.0.1-SNAPSHOT'

java {
	toolchain {
		languageVersion = JavaLanguageVersion.of(17)
	}
}

repositories {
	mavenCentral()
}

dependencies {
	implementation 'org.springframework.boot:spring-boot-starter-thymeleaf'
	implementation 'org.springframework.boot:spring-boot-starter-web'
	testImplementation 'org.springframework.boot:spring-boot-starter-test'
	testRuntimeOnly 'org.junit.platform:junit-platform-launcher'
}

tasks.named('test') {
	useJUnitPlatform()
}
```

#### Plugins 블록
```groovy
plugins {
	id 'java'
	id 'org.springframework.boot' version '3.4.4'
	id 'io.spring.dependency-management' version '1.1.7'
}
```
- `java`: Java 프로젝트로 인식하게 하는 기본 플러그인.
- `org.springframework.boot` : SpringBoot기능을 사용할 수 있게 해주는 플러그인(앱 실행, 자동 설정 등).
- `io.spring.dependency-management` : Spring이 권장하는 라이브러리 버전을 자동으로 관리해주는 플러그인.

#### Group 정보 및 버전
```groovy
group = 'lagom'
version = '0.0.1-SNAPSHOT'
```
- `group` : Maven의 Group ID개념. 보통 조직이나 프로젝트 이름.
- `version` : 현재 프로젝트 버전. `SNAPSHOT`은 개발 중인 버전임을 의미.

#### Java 버전 설정
```groovy
java {
	toolchain {
		languageVersion = JavaLanguageVersion.of(17)
	}
}
```
- Java 17을 사용하는 JDK Toolchain 설정.
- 개발 PC에 JDK 17이 없어도, Gradle이 자동으로 받아서 사용.
    (굉장히 유용한 기능!)

#### 의존성 저장소
```groovy
repositories {
	mavenCentral()
}
```
- 라이브러리를 받을 저장소 설정.
- `mavenCentral()`은 대부분의 오픈소스 Java 라이브러리가 등록된 중앙 저장소.

#### 의존성 관리
```groovy
dependencies {
	implementation 'org.springframework.boot:spring-boot-starter-thymeleaf'
	implementation 'org.springframework.boot:spring-boot-starter-web'
	testImplementation 'org.springframework.boot:spring-boot-starter-test'
	testRuntimeOnly 'org.junit.platform:junit-platform-launcher'
}
```

주요 라이브러리 설명:
- `spring-boot-starter-web`: Spring MVC, Tomcat 내장 서버 등 웹 개발 필수 구성 요소 포함.
- `spring-boot-starter-thymeleaf`: HTML 템플릿 엔진 Thymeleaf 연동.
- `spring-boot-starter-test`: JUnit, Mockito, Spring Test 등 포함된 테스트 패키지.
- `junit-platform-launcher`: JUnit 테스트 실행 런처 (JUnit 5에서 사용됨).

#### 테스트 설정
```groovy
tasks.named('test') {
	useJUnitPlatform()
}
```
- JUnit 5 (`JUnit Platform`) 기반으로 테스트를 실행하겠다는 설정.
- 기본값은 JUnit 4라서 이 설정이 필요함.
