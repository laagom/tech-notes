# [Python] 시프트 연산

> 작성일: 2025-06-15 · 태그: Language/Python/Calc, 기초

아래 한 줄짜리 함수는 **비트 연산** 가운데 _왼쪽 시프트(left shift)_ 를 이용해 `n`을 2의 거듭제곱 배만큼 키우는 역할을 합니다.

```python
def solution(n, t):     
	return n << t
```

---

### 1. `<<` 연산자의 의미

|연산자|이름|동작 요약|
|---|---|---|
|`<<`|**왼쪽 시프트**|피연산자의 비트열을 왼쪽으로 `t`칸 이동|

- **이동한 자리수(`t`)만큼 2를 거듭제곱**한 값과 동일한 효과

#### 예시 (32 → 64 → 128)

```python
n = 32        # 0b0010_0000
for t in range(4):      # t = 0,1,2,3
    print(t, n << t)
```

|t|이진수 결과|십진수 결과|
|---|---|---|
|0|0010 0000|32|
|1|0100 0000|64|
|2|1000 0000|128|
|3|1 0000 0000|256|

---
### 2. 함수 해석
```python
def solution(n, t):
    return n << t
```

- **매개변수**
    - `n` : 정수(int) — 시프트할 대상
    - `t` : 정수(int) — 몇 비트(몇 배) 이동할지
        
- **반환값**
    - `n × 2^t` 와 완전히 동일한 정수
        
- **시간 복잡도**
    - Python 내부 구현상 O( k ) 정도(비트 수 k에 선형)지만, 보통 산술 곱셈보다 **훨씬 빠른 상수 계수**를 가짐
        
- **용도**
    - 2의 거듭제곱 배수 계산을 빠르게 할 때
    - 비트 마스크·암호·통신 프로토콜 등 비트 단위 데이터 조작
        

---

### 3. 주의할 점

1. **음수 시프트**
    - `n << t`에서 `t`가 음수이면 `ValueError` 발생
	    ```python
		    5 << -1   # ValueError: negative shift count
	    ```
    
2. **음수 n**
    - 파이썬 정수는 무한 길이 2의 보수 표현을 가정하므로, 음수를 시프트하면 부호 비트까지 같이 이동해 값이 그대로 2^t 배가 됩니다.  
        예: `(-3) << 1 == -6`
        
3. **오버플로 걱정 없음**
    - 파이썬의 `int`는 임의 정밀도(BigInt)라 비트가 늘어나도 자동으로 자릿수를 확장합니다. (다만 메모리·속도는 늘어남)
        

---

### 4. 비교: 곱셈과 속도

|연산|의미|코드 예시|
|---|---|---|
|시프트|`n << t`|`n << 5`|
|산술 곱셈|`n * 2**t`|`n * 32`|

- **현대 파이썬**(CPython)에서는 둘 다 C 레벨 구현이라 실무 속도 차이는 미세하지만, 비트 시프트가 의도와 맞아떨어질 때 더 직관적·짧게 쓸 수 있습니다.
    

---

### 결론

이 함수는 “**n을 2의 t제곱만큼 빠르게 확대**”하는 간단·효율적인 구현입니다. 입력값에 음수 시프트만 주의하면, 대규모 반복 연산이나 비트 마스크 조작 상황에서 유용하게 쓸 수 있습니다.
