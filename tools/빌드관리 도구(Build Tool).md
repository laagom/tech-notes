# 빌드관리 도구(Build Tool)

>Maven과 Gradle은 모두 빌드관리 도구이다.
>
>빌드도구란, 소스코드에서 애플리케이션을 생성하면서 여러가지 **외부 라이브러리를 사용**하는데, 빌드관리 도구는 사용자가 관리할 필요 없이 **필요한 라이브러리들을 자동으로 관리**한다.
> (과거 프로젝트나 레거시 프로젝트는 Maven을 많이들 사용했지만 Gradle을 많이 사용하는 추세이다.)
> 
> 1) 종속성 다운로드 - 전처리(Preprocessing)
> 2) 소스모드를 바이너리 코드로 컴파일(Compile)
> 3) 바이너리 코드를 패키징(Packaging)
> 4) 테스트 실행(Testing)
> 5) 프로덕션 시스템에 배포(Distribution)
>    
> **빌드(Build)**
> 빌드는 소스코드 파일을 **컴퓨터에서 실행할 수 있는 독립적인 형태로 변환하는 과정과 결과**를 말한다.
> 
> 즉, 우리가 작성한 소스코드 (SpringBoot의 경우 .java 파일), 프로젝트에서 쓰인 각각의 파일 및 자원(.xml, .jpa, .jpg, .properties)을 jvm이나 tomcat같은 WAS가 인식할 수 있도록 패키징하는 과정 및 결과물을 일컫는다.
> 
> Ex) java프로젝트를 진행하면서 개발자가 작성한 Dog.java와 여러가지 정적 파일 등에 해당하는 resource가 존재하면 빌드를 통해 소스코드를 컴파일하여 .class로 변환하고 resource를 .class가 참조할 수 있는 적절한 위치로 옮기고 META-INF와 MANIFEST.MF들을 하나로 압축하는 과정을 의미한다.
